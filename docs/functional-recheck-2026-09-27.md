## 本轮发现与修复

1. **备份恢复失败后遗漏显示设置回滚。**恢复过程中写入时间轴显示设置后，如果地图恢复失败，业务数据回滚但设置没有回滚。现在保存原始设置值，失败时恢复，原来没有设置时删除对应键。回归分别覆盖已有/不存在设置，并确认恢复旧备份保留本机复盘和文字草稿。[代码](D:/obdidianprojects/line/src/services/workspaceBackup.ts:760)、[回归](D:/obdidianprojects/line/tests/e2e/workspace-backup-recovery.spec.ts)。
2. **录音期间切换日期后保存归属错误。**录音从一天开始，切换到另一日后暂停，原片段仍显示 recording 且音频时长为零。现在通过音频片段 ID 找到所属复盘，暂停、临时转写和最终识别都更新原来的记录。[代码](D:/obdidianprojects/line/src/review/components/ReviewView.tsx:213)。
3. **重新打开复盘时待识别音频未自动重试。**重试 effect 在本地记录加载完成前运行，随后没有再运行。现在等待本地初始化完成，并在初始化就绪时触发一次检查。[代码](D:/obdidianprojects/line/src/review/components/ReviewView.tsx:240)。第 2、3 项均在桌面/小屏复现后修复，[回归](D:/obdidianprojects/line/tests/e2e/review-data-safety.spec.ts)。
4. **项目详情尺寸测试读取未加载的内容。**外层抽屉显示不代表内部懒加载项目文档已就绪；补充等待文档容器后再检查横屏分栏和竖屏抽屉，保留所有尺寸断言。这是测试时序修正，没有修改产品布局。

新增 [review-api.test.ts](D:/obdidianprojects/line/tests/auth/review-api.test.ts) 通过内存 SQLite 执行实际迁移和 API SQL，验证创建、读取、更新、重复操作回执、旧版本冲突、无登录拒绝、无效内容拒绝及用户隔离。它不访问线上 D1。
