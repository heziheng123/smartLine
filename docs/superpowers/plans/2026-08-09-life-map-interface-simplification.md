# 人生地图界面精简、二级分类与滚动性能实施计划

## 实施顺序

1. 先修改领域与 Playwright 测试，固定目标隐藏、单列添加菜单、分组二级分类、空组、tombstone 和滚动突变不变量。
2. 重构 `LifeMapCreateMenu`、`LifeMapPlanningDrawer` 和 `LifeMapWorkspace`，移除目标 UI，收口时期重点/文字便签创建，实现三组结构管理。
3. 在 `LifeMapView` 中排除历史目标投影，删除目标节点分支和摘要行，加入紧凑下一关键日期按钮。
4. 将分类栏、项目标签、人生时期标题和负载标签改为 CSS sticky，删除滚动 rAF 中的批量 DOM 写入。
5. 建立项目/子阶段、分类日期范围和分类统计 `Map`，清理渲染时嵌套查找。
6. 更新产品、架构、数据迁移、操作和测试文档。
7. 运行 lint、TypeScript/depcheck、build、life-map、sync、system、桌面/小屏 Playwright 和全量 E2E，任何失败先定位根因再修复。

## 完成标准

- 历史目标底层保留但对 UI 完全不可见；
- 五项添加菜单、项目子阶段上下文入口和全局关键日期正常；
- 三个固定一级分类支持多个或零个二级分类；
- 人生时期不被固定栏遮挡，长期系统始终在分类轨道顶部；
- 滚动热路径没有随全部项目数量线性增长的 DOM 写入；
- schema 6、同步、备份、离线队列与历史数据无破坏。
