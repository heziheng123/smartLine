# 人生地图界面精简、二级分类与滚动性能设计

## 决策

- 目标实体从所有可见 UI 移除，历史数据在 schema 6、Store、同步和备份中原样保留。
- 添加菜单改为单列：项目、长期系统、关键日期、时期重点、文字便签；存在项目时增加子阶段上下文操作。
- 一级分类固定为学习、工作、生活；`LifeArea` 是可增删改移的二级分类，每组允许为空。
- 时期重点是日期范围的背景说明，不计算进度；文字便签是单日短备注。
- 128px 固定栏外层透明，只在实际泳道容器范围绘制背景，避免遮挡人生时期。
- 固定栏、项目标签、人生时期标题和负载标签使用 CSS sticky；滚动中不遍历画布节点写样式。

## 数据边界

schema 保持 6。不删除 `LifeGoal`、`kind: 'goal'`、`outcomeGoalId` 或历史复盘快照中的目标数据；新项目不写入 `outcomeGoalId`。UI 投影、范围、统计、搜索、空状态和新复盘仅纳入 `plan | phase`。

二级分类删除保留 tombstone。存在项目、子阶段、长期系统、时期重点、便签或领域关键日期引用时禁止删除。跨组移动只更新 `planGroupId`，引用对象的日期和二级分类 ID 不变。

## 布局与性能不变量

- 长期系统在同二级分类内始终优先占用最上方轨道。
- 子阶段继承父项目的分类、颜色、上下侧和轨道。
- 全局关键日期不受分类或项目筛选影响。
- 小地图关闭时，连续滚动不对主画布执行逐帧 DOM 写入。
- 滚动期间不提交主画布 React 视口状态，停止后最多统一提交一次。
- 父子索引、分类范围和统计为线性 `Map` 聚合，不在渲染中使用嵌套 `filter/find`。

## 可访问性和窄屏

添加菜单使用正确 menu 语义；领域筛选按学习/工作/生活分组；规划抽屉保留焦点循环和焦点返回。桌面端使用右侧抽屉，390px 小屏使用全屏面板，两者均保留 128px 泳道标签宽度。
