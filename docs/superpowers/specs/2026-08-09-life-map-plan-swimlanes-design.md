# 人生地图项目泳道设计规格

## 目标

只重构人生地图中主计划及其计划阶段的纵向展示：增加固定的“学习 / 工作 / 生活”大类、以现有人生领域作为子类、每个子类独立分轨，并提供大类换边与项目专用筛选。目标、人生阶段、长期系统、复盘、里程碑、注解、今天线、日期和语义缩放维持现有业务语义。

## 数据设计

- 固定大类 ID 为 `learning | work | life`，名称和基础色由代码常量定义，不允许新增、删除或改名。
- `LifeArea.planGroupId` 只控制该领域下主计划的泳道归属，不改变领域对目标、系统、主题和注解的语义。
- `LifeMapData.lifeMapPlanGroups` 保存三大类的 `placement`、稳定 `order` 和同步元数据。
- 默认映射：学习成长→学习、职业发展→工作，其余内置或未知旧领域→生活。
- 默认位置：学习在上方，工作和生活在下方；位置跨设备同步。
- 旧主计划的 `placement` 字段保留，但不参与新项目泳道布局。
- 引用中的领域继续禁止删除；用户可隐藏、排序或迁移引用后再删。

## 布局与交互

- 新泳道只处理 `plan` 与其 `phase`，阶段继承父计划的大类、领域、侧边和轨道。
- 每个领域独立使用半开区间 `[start, end + 1 day)` 分轨；结束日与下一计划开始日相同仍视为重叠。
- 左侧分类栏在所有视口固定为 128px，横向滚动时保持可见，纵向与画布内容对齐；长名称单行省略。
- 大类容器使用代表色 4px 色条与 5% 浅底。未来计划使用虚线和约 10% 填充，当前/过去计划使用实线和约 22% 填充。
- 保留既有进度、完成、维护、选中、阶段和未规划区间视觉。
- 大类标题提供整组上下切换；“全部 / 学习 / 工作 / 生活”项目筛选只影响项目泳道，且仅保存在当前会话。
- 年/月/周/日缩放不改变项目纵向身份；其他画布层只因避让而移动 Y 坐标。

## 迁移与容错

- 工作区 schema 升至 5；1–4 版数据和备份可升级，未来版本继续拒绝加载。
- 缺失、重复或非法的大类配置自动修复为固定三项；非法领域映射回退默认映射。
- 新集合进入实体级三方合并、离线写入队列、完整备份和恢复流程。
- 迁移不修改任何目标、计划、阶段、系统、里程碑或注解日期。

## 验收

- 领域测试覆盖默认映射、规范化、非法数据、最少轨道、包含结束日的重叠、阶段继承、筛选和上下高度。
- 同步/备份测试覆盖 schema 5、旧版升级、未来版本拒绝、离线队列和三方合并。
- 桌面与 390px Playwright 覆盖固定栏、横向滚动、换边持久化、阶段跟随、筛选独立、缩放稳定与既有操作回归。
- lint、类型/depcheck、构建、领域、同步、系统模拟和完整 E2E 均须无失败。
