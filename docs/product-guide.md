# SmartLine 产品与功能手册

## 1. 产品定位

SmartLine 用一条连续的数据链连接“长期方向 → 项目 → 可执行任务 → 每日安排 → 完成记录 → 复习与知识沉淀”。六个主视图共享业务身份：同一个项目任务可以出现在项目文档、周矩阵和每日安排中，完成后还能更新知识节点或复习轮次。人生地图是独立的长时间规划域，它不再展示或编辑目标实体。

主导航包含人生地图、项目规划、每日安排、周矩阵、艾宾浩斯复习和知识大盘。底部 Dock 会根据当前模块提供相应操作入口。

## 2. 核心概念

### 2.1 项目与项目文档

项目是年度时间轴上的 `Task`，包含起止日期、颜色、主线标记、完成状态和块列表。项目文档包含两种块：

- **文本块**：保存普通说明文本。
- **智能任务块**：保存标题、标签、日期、截止日、预计时长、复杂度、完成状态、知识节点绑定、复习同步开关和富文本正文。

智能任务分为普通任务、单词任务和通用数量任务。后两者是持续任务：`date` 表示可执行起始日，并通过每日记录累计数量；普通任务的 `date` 表示计划执行日。

### 2.2 任务状态

- **待规划**：普通任务没有计划日期，出现在周矩阵的待规划河流或冷冻仓。
- **已排期**：普通任务有计划日期；持续任务从起始日起按规则投影到每日安排。
- **已完成**：保存完成日期，并触发每日安排、EBB 和知识节点联动。
- **已归档**：从活动视图隐藏，保留在归档入口中。
- **自动冷冻**：未完成、未归档且计划日早于当前日期两天以上的普通单日任务会自动取消排期并记录 `frozenAt`；持续数量/单词任务不参与。一次扫描作为单个事务处理，可同时撤销任务日期和对应每日安排。

### 2.3 跨视图身份

项目任务使用项目 ID 和块 ID 组成稳定来源 ID。每日安排、周矩阵、撤销历史和项目整体顺延依靠该 ID 识别同一任务，不通过显示标题推断身份。

## 3. 人生地图

人生地图是独立数据域。主添加菜单只提供项目、长期系统、关键日期、时期重点和文字便签；存在项目时另有“给现有项目添加子阶段”。人生时期、二级分类、复盘和日期调整收纳在规划概览。

- 长期系统、项目与项目子阶段按固定的“学习 / 工作 / 生活”三大类展示，用户可在每组内自由增删多个二级分类；学习默认在时间轴上方，工作和生活默认在下方。
- 每个领域的长期系统始终排列在项目轨道上方；项目子阶段继承父项目的领域、侧边和轨道。
- 三大类不可增删或改名，但可以整组换到时间轴另一侧。
- 左侧 128px 分类栏在桌面和手机都固定，横向浏览数月后仍能看到大类与领域名。
- 关键日期默认全局，不要求先选择领域；可以在更多设置中关联项目或领域，并始终独立于项目筛选。
- 历史目标数据仅为同步和备份兼容保留，不出现在画布、搜索、编辑器、统计或复盘中。
- 长期系统可按日、周或月设定目标次数。
- 维护期会从有效天数中扣除；跨周/月统计按有效天数折算目标。
- 地图支持缩放、平移、轨道位置、上下标注、水平虚拟化和首次使用引导。固定栏和标签使用原生 sticky，小地图关闭时滚动不逐帧改写画布 DOM。
- 需要补充阶段时间概述时，从“添加 → 添加时期重点”直接在画布横向框选日期范围。时期重点只是背景说明，不计算进度。

推荐流程：先在规划概览的三个固定组内建立必要的二级分类，再从“添加”创建项目、长期系统或画布内容。分类会根据当前上下文自动给出且可编辑；项目内部再添加子阶段。

人生领域管理器可以修改领域所属的展示大类。该操作以及整组换边只改变展示结构，不修改任何日期。完整创建、兼容和交互规则见[人生地图信息架构](life-map-information-architecture.md)与[项目泳道开发指南](life-map-plan-swimlanes.md)。

## 4. 项目规划

### 4.1 年度时间轴

时间轴按月份切割跨月任务，并为重叠任务分配不冲突的行。主线任务优先占用高优先级轨道。分组可以手动设置日期，也可以从子项目自动计算范围。

支持新建、编辑和删除项目、分组、便签、里程碑；切换年份与显示密度；隐藏完成项；折叠分组；点击项目进入项目文档。

### 4.2 项目文档

项目文档支持块级编辑、斜杠命令、拖拽排序、搜索定位、智能任务弹窗、归档和恢复。智能任务正文以富文本 HTML 保存，渲染前通过 DOMPurify 净化。

任务可绑定多个知识节点，也可开启 EBB 自动同步。完成任务时，系统根据配置规划以下副作用：

- 更新任务完成状态和完成日期；
- 同步每日安排中的完成状态；
- 更新关联知识节点的学习状态；
- 创建、完成或调整对应复习链；
- 存在歧义时要求用户选择处理策略。

### 4.3 整项目顺延

项目文档支持把项目整体向后移动指定天数。操作同时移动项目起止日、项目内有日期的智能任务，以及与这些任务来源 ID 匹配的每日时段项和时间块。

时间块移动到目标日后如发生重叠，会降级为目标日相应时段中的普通排程项，避免静默丢失。撤销前会校验项目日期和每日安排是否仍与操作结果一致；检测到后续修改时拒绝覆盖。

## 5. 每日安排

每日安排提供两种视图：

- **时段模式**：将事项放入预设时段，支持自定义时段和顺序。
- **时间块模式**：以开始/结束时间显示时间轴块并检查重叠。

任务池汇总当前日期可执行的项目任务、数量任务和复习任务。已归档任务、归档知识节点关联任务会被过滤。任务可以拖入排程，也可从排程退回待规划。

完成普通任务会改变统一项目任务状态；数量/单词任务通过进度弹窗写入当日增量。自由事项只存在于每日安排，不反向创建项目任务。

### 5.1 每日复盘

复盘以日期为键，包含总结、评分和从当天已完成事项生成的活动记录。学习活动可以沉淀到知识节点复盘记录。复盘参与云同步、完整备份和本地快照。

## 6. 周矩阵与待规划

周矩阵将一周内的项目任务按日期分列，并提供跨日拖拽。无日期的普通任务进入待规划河流；持续任务保留开始日期，不参与普通待规划规则。

可切换周、跨日期移动任务、退回待规划、批量选择与调整、从冷冻仓恢复、打开任务详情和统一撤销最近操作。

## 7. 艾宾浩斯复习

### 7.1 复习链与轮次

同一主题或同一知识节点的复习任务组成复习链。每轮拥有稳定 `roundOrder`，改期不会改变轮次身份。旧数据缺少轮次序号时，会按原始计划日、当前日期和 ID 确定性补齐。

生成算法从起始日和间隔序列得到各轮日期；同主题日期冲突时向后顺延。启用智能分散后，还会检查每日任务数、积分负载、最大顺延天数和同主题最小间隔。

### 7.2 完成与逾期

复习轮次必须按顺序完成。逾期任务可按设置自动处理或通过批量面板调整。每日复习计划在容量约束下选择待复习内容，并保留应用计划前后的状态供撤销。

可用视图包括目录、矩阵、周看板、收件箱、轮次面板和设置。复杂度影响间隔、积分和预计时长。

## 8. 知识大盘

知识大盘以树结构组织知识节点。叶子节点的激活状态直接保存；非叶节点只有在所有未归档直接子节点都有效激活时才被视为激活。统计会递归汇总已激活叶子数和总叶子数。

节点可与项目任务和 EBB 复习链绑定。移动节点时 UI 阻止把节点放入自己的后代；加载归一化也会修复无效父级或循环引用。归档节点后，与它关联的活动任务和复习任务会从日常工作区过滤，但数据仍保留在归档库。

## 9. 定位、撤销和错误恢复

- 项目文档提供当前项目内定位；知识大盘的归档库保留归档搜索。旧版全局搜索入口已从应用壳层移除。
- 统一操作历史保存最近一次可撤销业务操作。撤销采用期望值保护，数据已被后续操作修改时拒绝覆盖。
- 每个懒加载主视图都有错误边界；单模块渲染失败不应拖垮整个应用。
- 数据写入失败会保留紧急日志或离线队列，并在连接恢复后重试。

## 10. 云同步与备份

“云同步与完整备份”提供连接/断开工作区、旧架构检查与迁移、完整 JSON 导入导出、本地快照、离线写入、冲突副本和可选 R2 月度归档。

首次连接统一工作区采用失败关闭策略：本地与云端都非空且摘要/hash 不一致时，不自动选择任何一方。迁移只复制旧房间，不删除旧数据；完成核对前应保留旧房间和 Public Key。

## 11. 使用边界

- 当前以单 GitHub 登录白名单为主要部署模型，不是完整多租户权限系统。
- 浏览器本地数据不会自动跨浏览器出现；必须明确启用云同步或使用备份迁移。
- Service Worker 不缓存 API、认证或 Liveblocks 请求；离线能力主要面向已加载静态资源和本地数据。
- 自动冷冻、批量调整和整项目顺延会改变计划日期，执行前建议确认完整备份可用。
