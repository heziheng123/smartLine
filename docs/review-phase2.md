# 语音复盘 Phase 2 部署

Phase 2 的录音先分块写入浏览器专用 IndexedDB `smart-line-review-audio`；D1 只保存片段元数据和识别后的文本，绝不保存音频字节、Base64 或可访问音频链接。录音开始时就建立片段记录；暂停思考只保存本机片段并释放麦克风，只有“说完了并识别”才会发起一次 ASR 请求。刷新或锁屏后，已落盘的片段会显示为“录音已中断”；可继续说（新片段）或完成并识别保存的部分。

部署前完成：

1. 在已绑定的 D1 数据库执行 [`migrations/0002_voice_transcripts.sql`](../migrations/0002_voice_transcripts.sql)。它保存一次性转写操作回执，方便网络重试，内容只有识别文本与供应商请求标识。
2. 在 Cloudflare Pages 的 Preview 和 Production 中新增**加密机密** `VOLCENGINE_ASR_API_KEY`。如未改动火山引擎默认资源，可选文本变量为 `VOLCENGINE_ASR_RESOURCE_ID=volc.bigasr.auc_turbo`。
3. 不要创建任何 `VITE_VOLCENGINE_*` 变量；密钥必须只存在于 Pages Function 环境中。

识别时，客户端将本机 PCM 分块临时组装为 WAV，并经同源 Pages Function 发送给 ASR 供应商一次。服务端在同一写入中保存权威转写、复盘版本和一次性回执；客户端在确认本地已保存该回执后，才按所选策略删除音频。默认“转写确认后删除”，也可保留 7 天或 30 天；失败、断网或无回执时绝不会删除。单段 WAV 上限为 8 MiB 且绝不超过 10 分钟；客户端会按浏览器实际采样率在达到大小上限时自动结束，16 kHz 下约为 4 分 22 秒。存储空间不足会阻止开始录音；每位用户每 15 分钟最多 20 次 ASR 请求。

验收清单：

1. 在 Chrome、Edge、Android Chrome、iOS Safari 和平板各录一段至少一秒的语音，分别验证麦克风允许与拒绝。
2. 录到一半刷新、锁屏或断网；重新打开后应看到中断提示和可识别的已保存部分。
3. 点“暂停思考”后确认没有网络 ASR 请求；点“说完了并识别”后才有一次请求。模拟 429、超时和 5xx 后，录音必须仍在本机且可重试。
4. 两台设备离线向同一日期各写一段记录，再联网；原始片段必须同时存在。若两端编辑同一人工条目，应显示可展开的冲突快照。
5. 验证三种保留策略：默认收到权威转写后删除；7/30 天策略可重试，过期清理后显示音频已不可用。
