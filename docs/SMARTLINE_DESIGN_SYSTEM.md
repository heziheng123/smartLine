# SmartLine Design System

版本：1.0 概念基线  
设计方向：Calm Intelligence / 静谧智能  
适用范围：项目规划、人生地图、每日安排、周矩阵、艾宾浩斯复习、知识大盘及所有全局弹层

## 1. 设计目标

SmartLine 是个人长期规划与知识工作台。界面应让复杂信息显得安静、可信、可掌控，而不是把功能数量直接暴露给用户。

核心原则：

1. 内容优先：内容画布保持实体、稳定，材质效果只用于导航、浮层和临时控制。
2. 渐进呈现：首屏只展示当前任务所需操作，低频能力收进菜单、检查器或二级面板。
3. 一致胜于装饰：六个工作区共享相同的页面标题、按钮、筛选、空状态和弹层语言。
4. 颜色有语义：高饱和颜色只用于选中、状态、关系与关键提醒。
5. 动效解释变化：动画用于说明层级、来源和去向，不用于持续吸引注意。

## 2. 品牌气质

关键词：克制、清晰、柔和、精确、长期主义。

避免：大面积玻璃、炫光渐变、霓虹描边、层层卡片、过度圆角、低对比灰字、无意义弹跳、装饰性图标堆叠。

品牌识别由三个元素构成：

- Smart Indigo：比系统蓝更沉静的靛蓝，用于核心选择与品牌瞬间。
- Timeline Line：细而精确的时间定位线，作为跨页面视觉母题。
- Quiet Canvas：大面积中性画布，让数据与计划成为视觉主角。

## 3. 基础 Token

### 3.1 色彩

| Token | 浅色主题 | 用途 |
|---|---:|---|
| Canvas | `#F5F5F7` | 应用背景 |
| Surface Primary | `#FFFFFF` | 主工作区、面板 |
| Surface Secondary | `#F9F9FB` | 次级分组、悬停底色 |
| Surface Elevated | `rgba(255,255,255,.78)` | Dock、Popover、浮层 |
| Text Primary | `#1D1D1F` | 标题、正文 |
| Text Secondary | `#6E6E73` | 描述、元信息 |
| Text Tertiary | `#98989D` | 非关键辅助信息 |
| Separator | `rgba(29,29,31,.10)` | 分隔线、外轮廓 |
| Accent | `#5E5CE6` | 品牌主色、当前选择 |
| Accent Hover | `#4F4DD6` | 主操作悬停 |
| Accent Soft | `#EEEEFF` | 选中背景、轻提示 |
| System Blue | `#007AFF` | 链接、系统操作 |
| Success | `#30A46C` | 完成、健康状态 |
| Warning | `#D98B00` | 期限风险、需关注 |
| Danger | `#D92D20` | 删除、失败、严重逾期 |

项目分类色采用“浅底 + 深字 + 单侧强调线”，禁止使用整块高饱和色作为长期内容背景。

### 3.2 字体

字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "PingFang SC", "Microsoft YaHei", sans-serif`

| 样式 | 字号 / 行高 | 字重 | 用途 |
|---|---|---:|---|
| Display | 28 / 36 | 600 | 页面核心标题、关键数据 |
| Title 1 | 22 / 30 | 600 | 页面标题 |
| Title 2 | 17 / 24 | 600 | 区块标题 |
| Body | 15 / 22 | 400 | 正文、主要控件 |
| Label | 13 / 18 | 500 | 标签、按钮、元信息 |
| Caption | 12 / 16 | 400 | 次级时间、辅助说明 |

规则：中文正文不低于 13px；不得仅依赖浅灰色表达禁用或次级状态；数字与时间尽量使用等宽数字特性。

### 3.3 间距与尺寸

基础单位为 4px。常用间距：4、8、12、16、20、24、32、40、48。

- 页面水平边距：桌面 24px，大屏 32px。
- 顶部工作区栏：56px。
- 普通控件高度：36px。
- 紧凑图标控件：32px。
- 主要操作与移动端触控目标：44px。
- 右侧检查器：320–360px，可收起。
- 内容最大阅读宽度：760px；数据画布不限制宽度。

### 3.4 圆角与阴影

| Token | 数值 | 用途 |
|---|---:|---|
| Radius S | 8px | 小按钮、标签 |
| Radius M | 12px | 输入框、控制组 |
| Radius L | 16px | 卡片、面板 |
| Radius XL | 22px | Dock、Popover、弹窗 |

内容层默认无阴影。仅浮动层使用柔和阴影：`0 12px 36px rgba(0,0,0,.10)`；模态层可提升至 `0 24px 64px rgba(0,0,0,.16)`。

## 4. 全局信息架构

### 4.1 页面骨架

每个工作区统一为三层：

1. Workspace Bar：页面标题、当前时间范围、一个主要动作、最多两个直接次要动作。
2. Content Canvas：页面独有数据与内容，不重复放全局导航。
3. Context Inspector：任务池、属性、详情或帮助，按需出现，可收起。

底部 Dock 只承担六个工作区切换。活动项使用浅色圆形或胶囊背景与品牌色图标，不以孤立小圆点作为唯一指示。

### 4.2 操作优先级

- Primary：每页最多一个实心品牌色按钮。
- Secondary：浅底或描边按钮，最多两个直接展示。
- Tertiary：无底图标按钮或文字按钮。
- Overflow：低频操作统一进入“更多”菜单。
- Destructive：默认不直接展示；进入菜单或确认弹窗后出现。

## 5. 核心组件

### Workspace Bar

- 左侧为标题与范围，中部不堆积统计，右侧为操作。
- 页面切换时结构位置保持稳定。
- 滚动场景可使用轻量半透明材质，但内容区保持实体。

### Segmented Control

- 2–4 个互斥选项使用分段控件。
- 选中项使用实体白色或 Accent Soft 背景，禁止同时使用粗边框和阴影。

### Icon Button

- 使用 Lucide 统一线宽与视觉尺寸。
- 默认无边框，Hover 出现柔和底色。
- 图标语义不明确时必须提供文字或 Tooltip。

### Task Bar / Event Card

- 以标题为第一视觉层级，时间与状态为第二层级。
- 分类色只出现在左侧 3px 色条、图标或浅色底。
- 完成状态降低饱和度，但仍保持文字可读。
- 选中态使用 Accent 描边或外发光，不改变卡片整体尺寸。

### Empty State

- 由一个 32px 线性图标、一句明确状态、一句说明和一个行动组成。
- 禁止使用低对比大段灰字。
- 空状态应放在用户视线中心，而不是顶部工具条下方的大片空白中。

### Popover / Dialog / Inspector

- Popover 用于短操作，Dialog 用于必须完成或确认的任务，Inspector 用于持续查看与编辑。
- 同一任务不得同时叠加 Drawer 与 Dialog。
- 所有弹层支持 Escape、焦点锁定和明确关闭入口。

## 6. 核心页面规则

### 6.1 项目规划

- 年度时间线是绝对视觉主角，顶部不再叠加另一套页面导航。
- 网格线降低到 5%–7% 黑色；月边界略强，日网格更弱。
- 当前日期使用一条精确的 Accent 线和紧凑日期标签。
- 任务条默认 24–28px 高，重叠时通过行距与层级处理，而不是增加饱和度。
- 待排期箱收进可展开的右侧 Inspector；有未排任务时显示数量徽标。

### 6.2 每日安排

- 上午、下午、晚上采用开放式 Section，不使用多层虚线框。
- 空段只展示“添加安排”一个入口；拖拽提示在拖动时出现。
- 右侧任务池为可收起 Inspector，默认显示最相关的 5–8 个任务。
- “时段 / 时间块”合并为一个 Segmented Control。

### 6.3 人生地图

- 顶部保留标题、时间范围、视图模式和主要“添加”动作。
- 分类筛选收进统一分段控件或筛选 Popover。
- 初次使用引导居中呈现，完成初始化后不再永久占据画布。
- 泳道标题保持固定；今日线、目标节点和时间刻度共享同一套视觉语义。

### 6.4 其他页面

- 周矩阵：周导航、分组、周期统一放入 Workspace Bar；空状态提供创建和拖入入口。
- 艾宾浩斯：合并统计、标签页与日期导航，筛选默认折叠；学习内容为首要层级。
- 知识大盘：保留沉浸式画布，左上展示轻量标题，搜索与筛选进入同一控制组，右侧使用节点 Inspector。

## 7. 动效

- Hover / Press：120–160ms。
- Popover / Tooltip：160–200ms。
- 页面与检查器：220–260ms。
- 标准缓动：`cubic-bezier(.16,1,.3,1)`。
- 允许轻微位移与透明度变化，不使用明显弹跳和长距离缩放。
- 必须遵循 `prefers-reduced-motion`。

## 8. 响应式

- 1440px 以上：完整工作区 + 右侧 Inspector。
- 1024–1439px：压缩水平边距，Inspector 覆盖式展开。
- 768–1023px：顶部操作收进 Overflow，Dock 保留。
- 767px 以下：底部 Dock 变为移动端 Tab Bar，复杂画布采用横向滚动或专用摘要视图。

## 9. 无障碍与质量门槛

- 正文与背景达到 WCAG AA 对比度。
- 任何状态不得仅依赖颜色表达。
- 键盘焦点环统一、清晰且不改变布局。
- 图标按钮必须有可访问名称。
- 支持 200% 缩放，不遮挡主要操作。
- 空状态、错误状态、加载状态与真实数据状态都需单独验收。

## 10. 概念稿验收标准

概念稿只有满足以下条件才可进入代码实施：

1. 三个核心页面看起来属于同一个产品。
2. 用户能在三秒内识别页面、当前时间范围和主要动作。
3. 首屏不超过一个实心主按钮。
4. 玻璃材质只用于 Dock、浮层或临时控制。
5. 内容层级主要依靠字号、留白和对比，而不是边框数量。
6. 保留现有主要业务结构，不以“简约”为由删除关键能力。
7. 空状态与有数据状态都具备明确下一步。
